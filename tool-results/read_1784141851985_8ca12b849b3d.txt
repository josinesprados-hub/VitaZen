   687→   687→**Insertion script (single output PDF):**
   688→   688→```python
   689→   689→from pypdf import PdfReader, PdfWriter
   690→   690→
   691→   691→A4_W, A4_H = 595.28, 841.89  # A4 in points
   692→   692→
   693→   693→def normalize_page_to_a4(page):
   694→   694→    """Scale a page to A4 if its dimensions don't match."""
   695→   695→    box = page.mediabox
   696→   696→    w, h = float(box.width), float(box.height)
   697→   697→    if abs(w - A4_W) > 2 or abs(h - A4_H) > 2:
   698→   698→        page.scale_to(A4_W, A4_H)
   699→   699→    return page
   700→   700→
   701→   701→def insert_cover(cover_pdf, body_pdf, output_pdf):
   702→   702→    """Insert cover as first page of body PDF → single output file."""
   703→   703→    writer = PdfWriter()
   704→   704→    # Cover as page 1
   705→   705→    cover_page = PdfReader(cover_pdf).pages[0]
   706→   706→    writer.add_page(normalize_page_to_a4(cover_page))
   707→   707→    # Body pages follow
   708→   708→    for page in PdfReader(body_pdf).pages:
   709→   709→        writer.add_page(normalize_page_to_a4(page))
   710→   710→    writer.add_metadata({'/Title': 'Report Title', '/Author': 'Z.ai', '/Creator': 'Z.ai'})
   711→   711→    with open(output_pdf, 'wb') as f:
   712→   712→        writer.write(f)
   713→   713→```

You must call `normalize_page_to_a4()` to unify dimensions before insertion.

   721→   721→**Cover design rules (summary - see cover.md for details):**
   722→   722→- Page size: `width: 794px; height: 1123px` (A4 at 96dpi)
   723→   723→- `body { margin: 0; padding: 0; overflow: hidden; }` - REQUIRED to avoid white borders

   725→   725→- **Background must be white or very light** (`#fff` / `#fafafa` / `#f5f8fb`), no dark solid backgrounds or gradient backgrounds
   726→   726→- Primary color used only for text, lines, geometric accents - never as large-area background
   727→   727→- Sophistication = whitespace + typography + restrained geometric accents
   728→   728→
   729→   729→**Cover Constitution (5-Layout System):**
   730→   730→- **Pick a layout (01/03/04/06/07)** from `typesetting/cover.md` that matches the document tone. No global default - every selection must be a deliberate design decision.
   731→   731→- **Maximum 4 components** on any cover. Typical recipe: Title + subtitle + 1 geometric accent + metadata.
   732→   732→- **Typography Scale**: Title ≈ 45pt, Subtitle ≈ 25pt, Meta ≥ 18pt (never below 14pt). Tiny text = FAIL.
   733→   733→- **Background layer (optional)**: See `typesetting/cover-backgrounds.md` for 3 recipes (A=极简弧线, B=工程十字轴+立柱, C=锐角切割+出血文字). Background renders BELOW all foreground content at 2-5% opacity.
   734→   734→- **Mandatory `<br>` chunking**: Title MUST break every 2-4 words (CJK) or 3-5 words (English). Single-line title = FAIL.
   735→   735→- **Bounding Box spatial dispersion**: Group elements into 2-3 bounding boxes at opposite regions (e.g., top-left + bottom-right). Never cluster everything into middle 40%.
   736→   736→- **Safe Zone**: 12% top/bottom, 14% left/right padding on cover pages.
   737→   737→- **No body text on cover**: Cover = title + subtitle + date + optional geometric decoration. All content goes to page 2+.
   738→   738→- **Cover page isolation**: Cover NEVER shares a page with TOC or body content. In Report route this is inherent (separate PDFs merged via pypdf). If output shows cover + TOC on same page = **critical bug**, regenerate immediately.

   741→   741→- **CJK body**: Use `TA_LEFT` + 2-char indent. Headings: no indent.

   766→   766→
   767→   767→### Standard Table Color Scheme (MUST USE for ALL tables)
   768→   768→
   769→   769→> **Colors MUST come from the `palette.cascade` output (Step 2).** The values below are variable names - they are populated by the cascade palette, never hardcoded.
   770→   770→
   771→   771→```python
   772→   772→# Colors from palette.cascade (Step 2) — NEVER hardcode hex values
   773→   773→# Table header uses HEADER_FILL (M tier, S ≤ 0.30) — NOT ACCENT (XS tier, too vivid)
   774→   774→TABLE_HEADER_COLOR = HEADER_FILL          # M tier — low-sat, blends with document body
   775→   775→TABLE_HEADER_TEXT  = colors.white          # White text for header (fixed)
   776→   776→TABLE_ROW_EVEN     = colors.white          # White for even rows
   777→   777→TABLE_ROW_ODD      = TABLE_STRIPE          # L tier — very subtle same-hue stripe
   778→   778→```
   779→   779→
   780→   780→> **⚠️ Why NOT `ACCENT` for table headers?** `ACCENT` is XS tier (S = 0.50-0.75), designed for tiny elements like badges and tags. Table headers occupy 5-20% of visual area (M tier). Using high-saturation `ACCENT` on table headers creates jarring color blocks that clash with the low-saturation body. `HEADER_FILL` (S ≤ 0.30) is specifically designed for this area ratio.
   781→   781→
   782→   782→### Table Rules
   783→   783→- Caption must be centered, added immediately after the table
   784→   784→- Entire table must be centered on the page
   785→   785→- **Header Row**: Dark background (from palette `HEADER_FILL`, M tier), white bold text
   786→   786→- **Cell Margins**: Left/Right at least 120-200 twips
   787→   787→- **Alignment**: Each body element within the same table must be aligned the same method
   788→   788→- **Color consistency**: All tables in one PDF must use the same `HEADER_FILL` + `TABLE_STRIPE` scheme
   789→   789→- **Spacing**: `Spacer(1, 18)` → Table → `Spacer(1, 6)` → Caption → `Spacer(1, 18)`
   790→   790→
   791→   791→### Table Centering Enforcement (MANDATORY)
   792→   792→
   793→   793→**Every table MUST be horizontally centered on the page. No exceptions.**
   794→   794→
   795→   795→```python
   796→   796→# ReportLab: ALWAYS set hAlign='CENTER'
   797→   797→table = Table(data, colWidths=col_widths, hAlign='CENTER')
   798→   798→
   799→   799→# Width rule: table total width should be 85-100% of available content width
   800→   800→available_width = doc.width  # or page_width - left_margin - right_margin
   801→   801→table_width = sum(col_widths)
   802→   802→if table_width < available_width * 0.85:
   803→   803→    # Scale up columns proportionally to fill space
   804→   804→    scale = (available_width * 0.90) / table_width
   805→   805→    col_widths = [w * scale for w in col_widths]
   806→   806→
   807→   807→# ❌ WRONG — no hAlign (defaults to LEFT, table drifts left)
   808→   808→table = Table(data, colWidths=[100, 200, 150])
   809→   809→
   810→   810→# ✅ RIGHT — explicit centering
   811→   811→table = Table(data, colWidths=[100, 200, 150], hAlign='CENTER')
   812→   812→```

   904→   904→### Table Width Management (⚠️ Prevent Table Overflow)
   905→   905→
   906→   906→**Most common table bug: columns overflow the right page margin because colWidths are hardcoded without checking available space.**
   907→   907→
   908→   908→**Iron Rule: The sum of all colWidths MUST NOT exceed `available_width`.**
   909→   909→
   910→   910→```python
   911→   911→from reportlab.lib.pagesizes import A4
   912→   912→from reportlab.lib.units import inch
   913→   913→
   914→   914→page_width = A4[0]  # 595.28pt
   915→   915→left_margin = 1.0 * inch   # 72pt (adjust to your doc's actual margins)
   916→   916→right_margin = 1.0 * inch  # 72pt
   917→   917→available_width = page_width - left_margin - right_margin  # ≈ 451pt
   918→   918→
   919→   919→# ─── Method 1: Proportional widths (RECOMMENDED) ───
   920→   920→# Define column ratios, auto-scale to fit available_width
   921→   921→col_ratios = [0.25, 0.40, 0.20, 0.15]  # must sum to 1.0
   922→   922→col_widths = [r * available_width for r in col_ratios]
   923→   923→table = Table(data, colWidths=col_widths)
   924→   924→
   925→   925→# ─── Method 2: Fixed + flex columns ───
   926→   926→# Some columns have fixed width (numbers, dates), rest fills remaining space
   927→   927→fixed_cols = {0: 80, 3: 60}  # col 0 = 80pt, col 3 = 60pt
   928→   928→fixed_total = sum(fixed_cols.values())
   929→   929→flex_count = 4 - len(fixed_cols)  # total columns minus fixed
   930→   930→flex_width = (available_width - fixed_total) / flex_count
   931→   931→col_widths = []
   932→   932→for i in range(4):
   933→   933→    col_widths.append(fixed_cols.get(i, flex_width))
   934→   934→table = Table(data, colWidths=col_widths)
   935→   935→
   936→   936→# ─── Method 3: Let ReportLab auto-calculate (simplest, less control) ───
   937→   937→# Pass colWidths=None - ReportLab auto-sizes based on content
   938→   938→# ⚠️ Risk: may still overflow if content is too wide
   939→   939→table = Table(data)  # no colWidths
   940→   940→```
   941→   941→
   942→   942→**Checklist before adding any table:**
   943→   943→1. Calculate `available_width` from your actual page size and margins
   944→   944→2. Sum all colWidths - must be ≤ `available_width`
   945→   945→3. For CJK text: characters are wider than Latin - budget ~12pt per CJK char at 10pt font
   946→   946→4. If a column has long text (descriptions, policies), use Paragraph() wrapping inside cells (not plain strings) - plain strings don't wrap and will overflow
   947→   947→5. Test with the longest expected content in each column
   948→   948→

  1008→  1008→## Auto-Generated Table of Contents
  1009→  1009→
  1010→  1010→### ❌ FORBIDDEN: Manual Table of Contents
  1011→  1011→**NEVER manually create TOC with hardcoded page numbers.**
  1012→  1012→
  1013→  1013→### ⚠️ MANDATORY: TOC requires a cover page
  1014→  1014→**Unless the user explicitly requests no cover, if a document has a Table of Contents, it MUST have a cover page.** Structure: Cover (page 1) → TOC (page 2) → Content (page 3+). Do not generate a TOC without a preceding cover page.
  1015→  1015→
  1016→  1016→### ✅ ALWAYS use auto-generated TOC:
  1017→  1017→
  1018→  1018→```python
  1019→  1019→from reportlab.platypus import SimpleDocTemplate, Paragraph, PageBreak, Spacer
  1020→  1020→from reportlab.platypus.tableofcontents import TableOfContents
  1021→  1021→from reportlab.lib.utils import simpleSplit
  1022→  1022→import hashlib
  1023→  1023→
  1024→  1024→class TocDocTemplate(SimpleDocTemplate):
  1025→  1025→    def afterFlowable(self, flowable):
  1026→  1026→        if hasattr(flowable, 'bookmark_name'):
  1027→  1027→            level = getattr(flowable, 'bookmark_level', 0)
  1028→  1028→            text = getattr(flowable, 'bookmark_text', '')
  1029→  1029→            key = getattr(flowable, 'bookmark_key', '')
  1030→  1030→            # MUST pass key as 4th element - without it, TOC entries won't have clickable links
  1031→  1031→            self.notify('TOCEntry', (level, text, self.page, key))
  1032→  1032→
  1033→  1033→doc = TocDocTemplate("document.pdf", pagesize=letter)
  1034→  1034→story = []
  1035→  1035→
  1036→  1036→toc = TableOfContents()
  1037→  1037→toc.levelStyles = [
  1038→  1038→    ParagraphStyle(name='TOCHeading1', fontSize=14, leftIndent=20, fontName='FreeSerif'),
  1039→  1039→    ParagraphStyle(name='TOCHeading2', fontSize=12, leftIndent=40, fontName='FreeSerif'),
  1040→  1040→]
  1041→  1041→story.append(Paragraph("<b>Table of Contents</b>", styles['Title']))
  1042→  1042→story.append(toc)
  1043→  1043→story.append(PageBreak())
  1044→  1044→
  1045→  1045→def add_heading(text, style, level=0):
  1046→  1046→    # Generate a unique bookmark key for this heading
  1047→  1047→    key = 'h_%s' % hashlib.md5(text.encode()).hexdigest()[:8]
  1048→  1048→    p = Paragraph('<a name="%s"/>%s' % (key, text), style)
  1049→  1049→    p.bookmark_name = text
  1050→  1050→    p.bookmark_level = level
  1051→  1051→    p.bookmark_text = text
  1052→  1052→    p.bookmark_key = key  # This key enables clickable TOC links
  1053→  1053→    return p
  1054→  1054→
  1055→  1055→# ⚠️ Orphan Heading Prevention (NOT a page break rule)
  1056→  1056→# If an H1 heading would appear in the bottom 15% of the page with no room
  1057→  1057→# for at least a few lines of content, push it to the next page.
  1058→  1058→# This is NOT "every H1 starts a new page" — it only triggers when the heading
  1059→  1059→# would be orphaned at the very bottom.
  1060→  1060→available_height = A4[1] - top_margin - bottom_margin
  1061→  1061→H1_ORPHAN_THRESHOLD = available_height * 0.15  # ~100pt ≈ 3.5cm — enough for heading + 2 lines
  1062→  1062→
  1063→  1063→def add_major_section(text, style):
  1064→  1064→    """Add an H1-level heading with orphan prevention (NOT forced page break)."""
  1065→  1065→    return [
  1066→  1066→        CondPageBreak(H1_ORPHAN_THRESHOLD),  # Only break if heading would be orphaned at page bottom
  1067→  1067→        add_heading(text, style, level=0),
  1068→  1068→    ]
  1069→  1069→
  1070→  1070→story.extend(add_major_section("Chapter 1: Introduction", styles['Heading1']))
  1071→  1071→# ... content ...
  1072→  1072→
  1073→  1073→doc.multiBuild(story)  # MUST use multiBuild for TOC
  1074→  1074→```
  1075→  1075→
  1076→  1076→**⚠️ CRITICAL TOC LINK RULES:**
  1077→  1077→1. `afterFlowable` MUST pass `key` as the 4th element in the notify tuple - without it, TOC entries have no clickable links
  1078→  1078→2. `add_heading` MUST set `bookmark_key` AND embed `<a name="key"/>` in the Paragraph text - this creates the link destination
  1079→  1079→3. The key must be unique per heading - use a hash of the heading text
