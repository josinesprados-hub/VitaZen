   646→   646→
   647→   647→### ⚠️ Cover Content Overflow Prevention (Mandatory)
   648→   648→
   649→   649→1. Cover section page margin is 0; total content height ≤ 15638 twips (1200 twips safety margin for cross-engine compatibility — MS Office renders large fonts taller than calculated).
   650→   650→2. Color block Table `height` must use `rule: "exact"` (never `"atLeast"`).
   651→   651→3. Each recipe code includes height budget annotations — verify during generation.
   652→   652→4. **`verticalAlign` must always be `"top"`**. Never use `"center"` or `"bottom"` in exact-height rows — content will be clipped or overflow. Use `spacing.before` on the first paragraph for vertical positioning.
   653→   653→5. **Title font size MUST be dynamically calculated via `calcTitleLayout()`** (see below). Never hardcode font sizes above 40pt for cover titles. Every recipe MUST call `calcTitleLayout()` before building title paragraphs.
   654→   654→6. **Never use `margins.top`/`margins.bottom` for vertical positioning inside exact-height cells**: Cell margins reduce available height unpredictably across MS Office and WPS. Use `spacing.before` on the first paragraph instead. Only `margins.left`/`margins.right` are safe.
   655→   655→7. **Dynamic spacing is mandatory**: Use `calcCoverSpacing()` to compute `spacing.before` values dynamically based on content element count and title line count. Never use fixed large spacing values (e.g., `before: 4500`) that assume a specific title length.
   656→   656→8. **Cover must be a single-page section**: The cover section must produce exactly ONE page. If content overflows to a second page, it means the height budget is violated. Common overflow causes and fixes:
   657→   657→   - Title font too large → use `calcTitleLayout()` to auto-reduce
   658→   658→   - Too many meta lines → reduce font size or remove less important lines
   659→   659→   - Fixed `spacing.before` values too large → use `calcCoverSpacing()` for dynamic values
   660→   660→   - Subtitle + English label + meta lines combined exceed budget → calculate total and reduce spacing
   661→   661→9. **Cover wrapper table MUST use explicit `allNoBorders`**: The outer 16838 wrapper table and ALL nested tables inside the cover MUST set borders to NONE explicitly. Never rely on docx-js default borders (`single/auto/sz=4`). Default borders add ~8 twips per edge, which causes MS Office to calculate a total height slightly exceeding 16838 → content overflows to a blank page 2. WPS is more lenient but MS Office is strict. **This is the #1 cause of "blank page 2 in MS Office but not in WPS".**
   662→   662→
   663→   663→```js
   664→   664→// ✅ MANDATORY: Define and use allNoBorders for every cover table
   665→   665→const NB = { style: BorderStyle.NONE, size: 0, color: "FFFFFF" };
   666→   666→const noBorders = { top: NB, bottom: NB, left: NB, right: NB };
   667→   667→const allNoBorders = { top: NB, bottom: NB, left: NB, right: NB,
   668→   668→                       insideHorizontal: NB, insideVertical: NB };
   669→   669→
   670→   670→new Table({
   671→   671→  borders: allNoBorders,  // ← MANDATORY on every cover table
   672→   672→  // ...
   673→   673→});
   674→   674→```
   675→   675→
   676→   676→10. **Decorative lines MUST use paragraph borders, NEVER text characters**: Horizontal decorative lines (accent strips, dividers, frame edges) must be implemented with `paragraph border.top` or `border.bottom` — never with text characters like `───`, `━━━`, `═══`, or `——————`. Character-drawn lines render at inconsistent widths across MS Office and WPS (font metrics differ), causing lines to appear truncated or misaligned. Paragraph borders render pixel-perfect in both engines and their width is controlled precisely via `indent.left` / `indent.right`.
   677→   677→
   678→   678→```js
   679→   679→// ✅ Correct — paragraph border (R2 style thick accent rule)
   680→   680→new Paragraph({
   681→   681→  indent: { left: 1000, right: 1000 },
   682→   682→  border: { top: { style: BorderStyle.SINGLE, size: 18, color: P.accent, space: 20 } },
   683→   683→  children: [],
   684→   684→})
   685→   685→
   686→   686→// ❌ FORBIDDEN — text character line (renders inconsistently)
   687→   687→new Paragraph({
   688→   688→  children: [new TextRun({ text: "───────────────", color: P.accent })]
   689→   689→})
   690→   690→```
   691→   691→9. **Post-generation overflow check (mandatory)**: After building cover children, estimate total height:
   692→   692→   ```js
   693→   693→   function estimateCoverHeight(elements) {
   694→   694→     let total = 0;
   695→   695→     for (const el of elements) {
   696→   696→       if (el instanceof Table) {
   697→   697→         // Sum row heights (exact rows) or estimate 400 twips per row
   698→   698→         const rows = el.root?.[0]?.rows || [];
   699→   699→         for (const row of rows) {
   700→   700→           total += row.height?.value || 400;
   701→   701→         }
   702→   702→       } else if (el instanceof Paragraph) {
   703→   703→         const fontSize = el.root?.[0]?.size || 24; // half-pts
   704→   704→         // ★ Use pt * 11.5 (= half-pt * 10 * 1.15) for accurate single-spacing estimate
   705→   705→         const lineHeight = Math.max(fontSize * 11.5, 276); // min 276 (default 12pt)
   706→   706→         const spacingBefore = el.spacing?.before || 0;
   707→   707→         const spacingAfter = el.spacing?.after || 0;
   708→   708→         total += lineHeight + spacingBefore + spacingAfter;
   709→   709→       }
   710→   710→     }
   711→   711→     return total;
   712→   712→   }
   713→   713→   // ★ Target: estimateCoverHeight(coverChildren) < 15638 (16838 - 1200 safety)
   714→   714→   ```

   718→   718→### ⚠️ Cover Title Layout — calcTitleLayout() (Mandatory for ALL Recipes)
   719→   719→
   720→   720→**Every cover recipe MUST use `calcTitleLayout()` to determine title font size and line breaks.** Hardcoding font sizes or passing the full title as a single TextRun is FORBIDDEN.
   721→   721→
   722→   722→**Every paragraph with font size > body text MUST set explicit line spacing** to prevent top clipping:
   723→   723→```js
   724→   724→// ★ MANDATORY: prevent inherited small line spacing from clipping large fonts
   725→   725→spacing: { line: Math.ceil(titlePt * 23), lineRule: "atLeast", after: 100 }
   726→   726→// Example: 36pt → line: 828; 44pt → line: 1012
   727→   727→```
   728→   728→Without this, the paragraph inherits body text line spacing (e.g., 560tw), which is shorter than the font height → top of characters gets clipped.
   729→   729→
   730→   730→```js
   731→   731→/**
   732→   732→ * Calculate safe font size and smart line breaks for cover titles.
   733→   733→ * MUST be called by every recipe before building title paragraphs.
   734→   734→ *
   735→   735→ * @param {string}  title          Full title string
   736→   736→ * @param {number}  maxWidthTwips  Available width for title text (twips, after subtracting margins/padding)
   737→   737→ * @param {number}  preferredPt    Desired max font size in pt (default 40)
   738→   738→ * @param {number}  minPt          Minimum allowed font size in pt (default 24)
   739→   739→ * @returns {{ titlePt: number, titleLines: string[] }}
   740→   740→ */
   741→   741→function calcTitleLayout(title, maxWidthTwips, preferredPt = 40, minPt = 24) {
   742→   742→  // Each CJK character width ≈ pt × 20 twips
   743→   743→  const charWidth = (pt) => pt * 20;
   744→   744→  const charsPerLine = (pt) => Math.floor(maxWidthTwips / charWidth(pt));
   745→   745→
   746→   746→  // Try from preferredPt downward until title fits in ≤ 3 lines
   747→   747→  let titlePt = preferredPt;
   748→   748→  let lines;
   749→   749→  while (titlePt >= minPt) {
   750→   750→    const cpl = charsPerLine(titlePt);
   751→   751→    if (cpl < 2) { titlePt -= 2; continue; }
   752→   752→    lines = splitTitleLines(title, cpl);
   753→   753→    if (lines.length <= 3) break;
   754→   754→    titlePt -= 2;
   755→   755→  }
   756→   756→
   757→   757→  // If still > 3 lines at minPt, force 3 lines
   758→   758→  if (!lines || lines.length > 3) {
   759→   759→    const cpl = charsPerLine(minPt);
   760→   760→    lines = splitTitleLines(title, cpl);
   761→   761→    titlePt = minPt;
   762→   762→  }
   763→   763→
   764→   764→  return { titlePt, titleLines: lines };
   765→   765→}
   766→   766→
   767→   767→/**
   768→   768→ * Smart Chinese title line-breaking — breaks at semantic boundaries, never mid-word.
   769→   769→ *
   770→   770→ * Rules:
   771→   771→ * 1. Prefer breaking after particles, punctuation, connectors, underscores, spaces
   772→   772→ * 2. Never split a compound word (e.g., "管理规范" must not become "管理规" + "范")
   773→   773→ * 3. No single-character orphan on the last line — merge into previous line
   774→   774→ * 4. If no good break point found within 60-130% of charsPerLine, break at charsPerLine
   775→   775→ *
   776→   776→ * @param {string} title        Full title string
   777→   777→ * @param {number} charsPerLine Max characters per line at current font size
   778→   778→ * @returns {string[]}          Array of line strings
   779→   779→ */
   780→   780→function splitTitleLines(title, charsPerLine) {
   781→   781→  if (title.length <= charsPerLine) return [title];
   782→   782→
   783→   783→  // Characters that are safe break points (break AFTER these)
   784→   784→  const breakAfter = new Set([
   785→   785→    ...'，。、；：！？',              // CJK punctuation
   786→   786→    ...'的与和及之在于为',            // CJK particles/prepositions
   787→   787→    ...'-_—–·/',                     // connectors
   788→   788→    ...' \t',                         // whitespace
   789→   789→  ]);
   790→   790→
   791→   791→  const lines = [];
   792→   792→  let remaining = title;
   793→   793→
   794→   794→  while (remaining.length > charsPerLine) {
   795→   795→    let breakAt = -1;
   796→   796→
   797→   797→    // Search backward from charsPerLine to 60% for a break point
   798→   798→    for (let i = charsPerLine; i >= Math.floor(charsPerLine * 0.6); i--) {
   799→   799→      if (i < remaining.length && breakAfter.has(remaining[i - 1])) {
   800→   800→        breakAt = i;
   801→   801→        break;
   802→   802→      }
   803→   803→    }
   804→   804→
   805→   805→    // If not found, search forward up to 130%
   806→   806→    if (breakAt === -1) {
   807→   807→      const limit = Math.min(remaining.length, Math.ceil(charsPerLine * 1.3));
   808→   808→      for (let i = charsPerLine + 1; i < limit; i++) {
   809→   809→        if (breakAfter.has(remaining[i - 1])) {
   810→   810→          breakAt = i;
   811→   811→          break;
   812→   812→        }
   813→   813→      }
   814→   814→    }
   815→   815→
   816→   816→    // Last resort: break at charsPerLine, but avoid splitting compound CJK words
   817→   817→    if (breakAt === -1) {
   818→   818→      breakAt = charsPerLine;
   819→   819→      // If both chars at the break boundary are CJK (likely a compound word),
   820→   820→      // step back 1 char to keep the word together
   821→   821→      const prevChar = remaining[breakAt - 1];
   822→   822→      const nextChar = remaining[breakAt];
   823→   823→      if (prevChar && nextChar &&
   824→   824→          !breakAfter.has(prevChar) && !breakAfter.has(nextChar) &&
   825→   825→          /[\u4e00-\u9fff]/.test(prevChar) && /[\u4e00-\u9fff]/.test(nextChar)) {
   826→   826→        breakAt = breakAt - 1;
   827→   827→      }
   828→   828→    }
   829→   829→
   830→   830→    lines.push(remaining.slice(0, breakAt).trim());
   831→   831→    remaining = remaining.slice(breakAt).trim();
   832→   832→  }
   833→   833→  if (remaining) lines.push(remaining);
   834→   834→
   835→   835→  // Prevent single-character orphan on last line — merge into previous
   836→   836→  if (lines.length > 1 && lines[lines.length - 1].length <= 2) {
   837→   837→    const last = lines.pop();
   838→   838→    lines[lines.length - 1] += last;
   839→   839→  }
   840→   840→
   841→   841→  return lines;
   842→   842→}
   843→   843→
   844→   844→/**
   845→   845→ * Calculate dynamic spacing values for cover elements to fit within page height.
   846→   846→ *
   847→   847→ * @param {object} params
   848→   848→ * @param {number} params.titleLineCount   Number of title lines
   849→   849→ * @param {number} params.titlePt          Title font size in pt
   850→   850→ * @param {boolean} params.hasSubtitle     Whether subtitle exists
   851→   851→ * @param {boolean} params.hasEnglishLabel Whether English label exists
   852→   852→ * @param {number} params.metaLineCount    Number of meta info lines
   853→   853→ * @param {number} params.fixedHeight      Sum of fixed-height elements (color strips, accent bars, footer) in twips
   854→   854→ * @param {number} params.pageHeight       Total page height in twips (default 16838)
   855→   855→ * @returns {{ topSpacing, midSpacing, bottomSpacing }}  Spacing values in twips
   856→   856→ */
   857→   857→function calcCoverSpacing(params) {
   858→   858→  const {
   859→   859→    titleLineCount = 1, titlePt = 36, hasSubtitle = false,
   860→   860→    hasEnglishLabel = false, metaLineCount = 0,
   861→   861→    fixedHeight = 800, pageHeight = 16838,
   862→   862→    marginTop = 0, marginBottom = 0,   // ★ NEW: pass actual section margins
   863→   863→  } = params;
   864→   864→
   865→   865→  // ★ Safety margin: 1200 twips (cross-engine: MS Office renders large fonts
   866→   866→  // taller than calculated; extra 400tw buffer prevents footer clipping)
   867→   867→  const SAFETY = 1200;
   868→   868→  // ★ Subtract page margins from available height (cover section may have margins)
   869→   869→  const usableHeight = pageHeight - marginTop - marginBottom - SAFETY;
   870→   870→
   871→   871→  // ★ Accurate height estimation per element:
   872→   872→  const titleHeight = titleLineCount * (titlePt * 23 + 200);
   873→   873→  const subtitleHeight = hasSubtitle ? (12 * 23 + 600) : 0;
   874→   874→  const englishLabelHeight = hasEnglishLabel ? (9 * 23 + 600) : 0;
   875→   875→  const metaHeight = metaLineCount * (10 * 23 + 100);
   876→   876→
   877→   877→  // ★ Account for implicit paragraph heights:
   878→   878→  const implicitParaHeight = 3 * 300;
   879→   879→
   880→   880→  const contentHeight = titleHeight + subtitleHeight + englishLabelHeight +
   881→   881→                        metaHeight + fixedHeight + implicitParaHeight;
   882→   882→
   883→   883→  const remainingSpace = usableHeight - contentHeight;
   884→   884→  const safeRemaining = Math.max(remainingSpace, 400);
   885→   885→
   886→   886→  // ★ Footer protection: bottomSpacing must be ≥ FOOTER_MIN to prevent
   887→   887→  // footer + accent line from being clipped at the cell bottom edge
   888→   888→  const FOOTER_MIN = 800;
   889→   889→  const rawTop = Math.floor(safeRemaining * 0.45);
   890→   890→  const rawBottom = Math.floor(safeRemaining * 0.45);
   891→   891→  const bottomSpacing = Math.max(rawBottom, FOOTER_MIN);
   892→   892→  const topSpacing = Math.max(rawTop - Math.max(0, FOOTER_MIN - rawBottom), 400);
   893→   893→  const midSpacing = Math.max(safeRemaining - topSpacing - bottomSpacing, 0);
   894→   894→
   895→   895→  return { topSpacing, midSpacing, bottomSpacing };
   896→   896→}
   897→   897→```

   926→   926→### ⚠️ CRITICAL — Cover Section Non-Negotiables (ALL Recipes)
   927→   927→
   928→   928→These 3 properties are MANDATORY for every cover implementation (R1–R7). Omitting ANY of them causes cover layout failure:
   929→   929→
   930→   930→1. **Cover section margin = 0**: The cover MUST be in its own section with `page.margin: { top: 0, bottom: 0, left: 0, right: 0 }`. Non-zero margins shrink the wrapper away from page edges → white gaps around the cover ("cover not filling the page"). This is the #1 cause of broken cover layouts.
   931→   931→
   932→   932→2. **Wrapper row exact height**: The outer wrapper table row MUST set `height: { value: 16838, rule: "exact" }`. Without this, content overflow pushes to page 2, or insufficient content leaves bottom whitespace.
   933→   933→
   934→   934→3. **Wrapper table borders = allNoBorders**: MUST explicitly set `borders: allNoBorders`. Default docx-js borders add ~8 twips per edge. MS Office includes border thickness in exact-height calculation → total exceeds 16838 → blank page 2 (WPS is lenient, MS Office is strict).
   935→   935→
   936→   936→**Cover section template (copy this for every Recipe):**
   937→   937→```js
   938→   938→sections: [
   939→   939→  {
   940→   940→    // ⚠️ Cover section — margin MUST be 0, separate from body
   941→   941→    properties: {
   942→   942→      page: {
   943→   943→        size: { width: 11906, height: 16838 },
   944→   944→        margin: { top: 0, bottom: 0, left: 0, right: 0 },
   945→   945→      },
   946→   946→    },
   947→   947→    children: buildCoverRX(config), // ← replace with actual recipe function
   948→   948→  },
   949→   949→  {
   950→   950→    // Body section — normal margins
   951→   951→    properties: {
   952→   952→      type: SectionType.NEXT_PAGE,
   953→   953→      page: {
   954→   954→        size: { width: 11906, height: 16838 },
   955→   955→        margin: { top: 1440, bottom: 1440, left: 1701, right: 1417 },
   956→   956→      },
   957→   957→    },
   958→   958→    children: [...bodyContent],
   959→   959→  },
   960→   960→]
