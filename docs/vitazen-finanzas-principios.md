# VitaZen Finanzas — Principios de producto
*Documento interno. No para usuarios. Para cada decisión que tomemos.*

---

## Lo que VitaZen Finanzas es

Un espejo financiero. No un sistema de gestión, no un coach, no un juez.
Un lugar donde el usuario ve con claridad cómo su dinero refleja quién es,
sin que nadie le diga cómo debería sentirse al respecto.

**El registro manual es el producto, no un inconveniente.**
La consciencia requiere presencia. La automatización la elimina.

---

## Lo que VitaZen Finanzas nunca hace

**Nunca juzga.**
Sin rojos de alerta, sin exclamaciones, sin "¡cuidado!", sin "has superado tu límite."
El usuario es un adulto. La app observa, no advierte.

**Nunca rellena el silencio.**
Si no hay nada real que aportar, no se dice nada.
Ningún mensaje motivacional de relleno, ningún "¡Buen trabajo!" automático,
ninguna notificación inventada para generar engagement.
Cuando VitaZen habla, tiene algo real que aportar.

**Nunca usa lenguaje financiero para generar presión, urgencia o juicio.**
"Saldo", "ahorro", "ingresos", "gastos" son palabras correctas cuando aportan claridad.
El problema nunca es el término. Es el tono frío, ansioso o evaluador.
VitaZen usa lenguaje financiero solo cuando ayuda al usuario a entender.
Nunca para que se sienta vigilado.

**Nunca condiciona la reflexión con datos.**
El orden es siempre: primero identidad, luego números. Nunca al revés.
Si el usuario ve las métricas primero, ya está condicionado emocionalmente
antes de poder reflexionar con libertad.

**Nunca conecta al banco.**
La presencia en cada registro es lo que genera consciencia.
Automatizar el registro es destruir el producto.

**Nunca pone un número que resuma "qué tan bien lo estás haciendo."**
Sin scores de salud financiera, sin semáforos, sin índices de bienestar económico.
VitaZen no puntúa vidas.

**Nunca empuja.**
Sin notificaciones de gasto en tiempo real, sin urgencia fabricada.
El usuario viene cuando quiere. La app está, no insiste.

**Nunca convierte la vida del usuario en un sistema de optimización.**
VitaZen no es una herramienta de mejora continua.
No hay métricas que maximizar, ni hábitos que perfeccionar, ni vidas que eficientizar.
Hay una persona tratando de entenderse. Eso es todo.

---

## El orden que define todo

```
Primero identidad → luego números
```

Este principio no es solo filosofía. Define:
- la arquitectura de cada pantalla
- el orden de cada flujo
- el tono de cada texto
- el ritmo emocional de cada momento en la app

---

## Las tres preguntas que filtran cada decisión

Antes de añadir cualquier feature, texto, pantalla o cambio:

**1. ¿Esto añade consciencia o añade ruido?**
Si la respuesta no es claramente "consciencia", no entra.

**2. ¿Esto le dice al usuario cómo sentirse, o le muestra algo y se calla?**
VitaZen muestra. El usuario interpreta. Siempre.

**3. ¿Esto podría estar en cualquier app financiera, o solo tiene sentido en VitaZen?**
Si podría estar en Fintonic, no entra.
Si solo tiene sentido aquí, puede entrar.

---

## El tono en una frase

**Observación calmada.**

No sobriedad clínica. No poesía de diseño. No coaching encubierto.
Una voz que nota, que refleja, que no concluye.

El silencio es parte del diseño.
Las apps premium saben cuándo callar.

---

## Lo que construye el alma del producto

Todo lo demás es secundario o prescindible. El núcleo real de VitaZen Finanzas son estas cinco piezas:

1. **Quick Capture** — fricción cero en el momento del registro
2. **Intenciones** — tranquilidad, crecimiento, necesidad, disfrute
3. **"¿Qué pasó?"** — el contexto humano detrás de cada número
4. **Balance de intenciones** — la home no muestra cuánto, muestra hacia dónde
5. **Cierre mensual** — primero la reflexión, luego los datos

Con el tiempo, estas cinco piezas construyen algo que ninguna app financiera puede ofrecer:
el rastro de quién estaba siendo el usuario cuando tomaba sus decisiones económicas.

No qué gastó. Quién era cuando gastó.
